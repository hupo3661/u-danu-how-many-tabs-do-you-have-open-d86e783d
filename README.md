An honest confession, in digits only: how many browser tabs are open right now. The program writes one number — the entrant's real tab count, read off the browser's tab counter — to `/output/entry.txt`. No words, no explanation, just the number. Four digits, specific, unrounded: the count of someone who never closes a "read later" tab.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set). The output is exactly the digits, no trailing newline, so it passes the competition's gate of 1 to 5 characters.
